#定义 

设 C 是 $\mathbb{C}$ 内的一条分段光滑曲线 $z:[a,b] \to \mathbb{C}$ ，他的正方向指参数 t 增加的方向。函数 f(z) 在 C 上有定义，在闭区间 $[a,b]$ 上取一组分点 $a=t_{0}<t_{1}<\dots<t_{n}=b$，得 $[a,b]$ 的一个划分，记为 $\mathcal{P}={t_{0},\dots,t_{n}}$。产生一组分点 $z_{k}=z(t_{k}),0\leq k\leq n$， 在弧段 $z_{k-1}\to z_{k}$ 上取点 $\zeta_{k}$ ，并考虑 Riemann和
$$S(\mathcal{P})=\sum_{k=1}^nf(\zeta_{k})(z_{k}-z_{k-1})$$
记划分的长度 $||\mathcal{P}||=max\{t_{k}-t_{k-1}|1\leq k\leq n\}$。若当 $||\mathcal{P}|| \to 0$时，Riemann 和的极限存在，且与 $\zeta_{k}$ 的选取无关，则称此极限为函数 f(z) 沿曲线 C 的积分，记为
$$\int_{C}f(z)dz=\lim_{ ||\mathcal{P}|| \to 0 } \sum_{k=1}^n f(\zeta_{k})(z_{k}-z_{k-1})$$
