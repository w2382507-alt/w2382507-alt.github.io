#定理 

多元函数 $z=f(x,y)$ 在点 (x,y) 可微分，则函数在该点必定连续 ^6b79f0

---

**证**
由于多元函数 $z=f(x,y)$ 在点 (x,y) 可微分（[[多元函数的可微]]），得
$$\Delta z=A\Delta x+B\Delta y+o(\rho)$$
令 $\rho\to0$，可得
$$\lim_{ \rho \to 0 } \Delta z=0$$
从而
$$\lim_{ (\Delta x,\Delta y) \to (0,0) } f(x+\Delta x,y+\Delta y)=\lim_{ \rho \to 0 } [f(x,y) + \Delta z] = f(x,y)$$
由[[多元函数的连续性#^e9e510]]，从而函数$z=f(x,y)$ 在点 (x,y) 连续
